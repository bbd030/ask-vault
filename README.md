\# AskVault



一个基于 RAG（检索增强生成）的私有知识库问答系统。



\## 项目目标



用户提供文档并提出问题，系统检索相关片段，生成回答并展示引用来源。



\## 第一版功能计划



\- 读取 TXT 文档

\- 将文档切分为片段

\- 对片段进行向量化与检索

\- 基于检索结果生成回答

\- 展示引用来源
